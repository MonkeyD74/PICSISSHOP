# PICSIS SHOP

Catálogo web con simulador de crédito y contacto por WhatsApp.

## Configuración rápida

Antes de deploy, edita `app/page.jsx` y cambia:

```js
const WA_NUMBER = "521XXXXXXXXXX";
```

Pon tu número con código de país (México = `52`, +1 para celular = `521`, luego los 10 dígitos sin espacios).

## Stack

- Next.js 14 (App Router)
- React 18
- Sin dependencias externas

## Deploy

Importar este repo en [vercel.com](https://vercel.com) y dar Deploy. No requiere configuración adicional.
